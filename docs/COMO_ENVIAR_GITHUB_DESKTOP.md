# 📦 Como Enviar Projeto para GitHub - Método Mais Fácil

## 🎯 Método Recomendado: GitHub Desktop

### Passo 1: Instalar GitHub Desktop

1. Acesse: https://desktop.github.com/
2. Clique em "Download for Windows"
3. Instale o programa normalmente
4. Abra o GitHub Desktop

### Passo 2: Fazer Login

1. No GitHub Desktop, clique em "Sign in to GitHub.com"
2. Faça login com sua conta: **FilipedaSilva25**
3. Autorize o GitHub Desktop se pedir

### Passo 3: Adicionar Repositório Local

1. No GitHub Desktop, clique em **File** → **Add Local Repository**
2. Clique em **Choose...**
3. Navegue até: `c:\Users\Filipe da Silva\Downloads\Projeto Vida copia cursor`
4. Selecione a pasta e clique em **Add**

### Passo 4: Publicar no GitHub

1. O GitHub Desktop vai mostrar todos os arquivos
2. No canto inferior esquerdo, você verá:
   - **Current branch:** main
   - **Uncommitted changes** (se houver)
3. Se houver mudanças não commitadas:
   - Digite uma mensagem (ex: "Atualização final")
   - Clique em **Commit to main**
4. Clique no botão **Publish repository** (ou **Push origin** se já estiver conectado)
5. Escolha:
   - **Name:** mylife-os (ou deixe como está)
   - **Description:** "Sistema AXIS - Gestão de Inventário"
   - **Keep this code private:** (deixe desmarcado se quiser público)
6. Clique em **Publish Repository**

### ✅ Pronto!

Todos os arquivos serão enviados para: https://github.com/FilipedaSilva25/mylife-os

## 🔄 Para Atualizações Futuras

Depois que publicar, para enviar novas mudanças:

1. Faça suas alterações nos arquivos
2. Abra o GitHub Desktop
3. Você verá as mudanças listadas
4. Digite uma mensagem de commit
5. Clique em **Commit to main**
6. Clique em **Push origin**

## 📝 Alternativa: Upload Manual (Não Recomendado)

Se preferir fazer upload manual (não mantém histórico Git):

1. Acesse: https://github.com/FilipedaSilva25/mylife-os
2. Clique em **Add file** → **Upload files**
3. Arraste a pasta inteira ou arquivos individuais
4. Digite uma mensagem de commit
5. Clique em **Commit changes**

⚠️ **Atenção:** Este método não é ideal para muitos arquivos e não mantém o histórico Git corretamente.

## 🆘 Problemas Comuns

### "Repository already exists"
- O repositório já existe no GitHub
- Use **Push origin** ao invés de **Publish repository**

### "Authentication failed"
- Verifique se está logado no GitHub Desktop
- File → Options → Accounts → Sign out e Sign in novamente

### "Nothing to commit"
- Todos os arquivos já estão commitados
- Use **Push origin** para enviar ao GitHub

# Roteiro – vídeo de apresentação do site AXIS

Objetivo: **mostrar o visual e as funções principais** em 3–6 minutos (ajusta ao que pedirem).

## Antes de gravar

1. Usa o **site em produção** ou local com dados de demonstração limpos.
2. Resolução: **1920×1080**, navegador em **janela maximizada** (ou modo apresentação).
3. Ferramentas: **OBS Studio**, **Xbox Game Bar** (Win+G), ou **Clipchamp** no Windows.
4. Desliga notificações, fecha abas extra, zoom do browser em **100%**.

## Estrutura sugerida (com tempos)

| Tempo | O quê |
|--------|--------|
| 0:00–0:20 | **Abertura:** logo/título “AXIS”, URL no browser, frase: sistema de gestão (inventário, packing, preventivas). |
| 0:20–0:50 | **Login / entrada:** ecrã inicial, login (sem mostrar palavra-passe real — usa conta demo ou borra o campo). |
| 0:50–1:30 | **Dashboard / navegação:** menu principal, aspecto visual (cores, tipografia), 1–2 módulos que queiras destacar. |
| 1:30–2:30 | **Inventário ou módulo core:** lista, filtro, detalhe de um item (mostra que “funciona”). |
| 2:30–3:30 | **Packing Machine / preventivas** (se for prioridade): página, gráficos ou tabela, formulário ou histórico. |
| 3:30–4:10 | **Perfil utilizador:** nome, setor, matrícula AXIS (readonly), foto se existir. |
| 4:10–4:40 | **Mobile (opcional):** gravação rápida no telemóvel ou janela estreita para mostrar responsivo. |
| 4:40–5:00 | **Encerramento:** URL de novo, contacto ou próximo passo (“disponível em …”). |

## Dicas

- **Rato calmo:** pausas de 1 s após cada clique para o espectador acompanhar.
- Se algo falhar na gravação, **corta** no editor — não precisa ser uma só tomada.
- Música de fundo: só se for **royalty-free** e volume baixo, ou sem música para tom mais corporativo.

## Entrega

- Exporta **MP4 (H.264)** para máxima compatibilidade (WhatsApp, e-mail, apresentações).

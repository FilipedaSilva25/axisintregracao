Configurar o bot na Meta (WhatsApp Cloud API) – funciona 24h sem QR

Passo 1: Criar app na Meta

Acesse o painel de desenvolvedores da Meta e crie um app (ou use um existente):

developers.facebook.com/apps
  1. Clique em Criar app → Outros → Consumidor
  2. Preencha nome (ex: AXIS Bot) e e-mail
  3. Adicione o produto WhatsApp no app

Passo 2: Configurar Webhook

No app, vá em WhatsApp → Configuração → Webhook.

Clique em Editar ou Configurar e informe:

URL de retorno de chamada:

https://SEU-DOMINIO.com/api/whatsapp/cloud-webhook

Importante: Use sua URL pública HTTPS (ex: https://seu-app.onrender.com). Localhost não funciona com a Meta.

Token de verificação:

axis-packing-bot

Passo 3: Inscrever-se em mensagens

Após salvar o webhook, em Campos de webhook marque:

  • ☑ messages

Passo 4: Obter Token e Phone Number ID

Na mesma tela WhatsApp → Configuração:

  1. Token de acesso temporário: clique em "Gerar" e copie
  2. Phone number ID: aparece em "De" – copie o ID numérico

Para produção, crie um token permanente em Configurações do sistema → Usuário do sistema.

Passo 5: Adicionar ao .env

Crie ou edite o arquivo .env na raiz do projeto e adicione:

WA_CLOUD_API_ACCESS_TOKEN=seu_token_aqui WA_PHONE_NUMBER_ID=seu_phone_number_id WA_WEBHOOK_VERIFY_TOKEN=axis-packing-bot

Substitua seu_token_aqui e seu_phone_number_id pelos valores do Passo 4.

Reinicie o servidor: npm start
